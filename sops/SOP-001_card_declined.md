# SOP-001

Title: Debit Card Transaction Declined
Category: Cards
Issue: Card Declined
Support Level: L1
Version: 1.0
Status: Active

## Symptoms

Customer reports that their debit card transaction has been declined.

Examples:

- Card payment declined
- POS transaction failed
- Online card payment declined
- Card worked previously but is now being declined

## Resolution Steps

### Step 1

Identify the transaction type.

Determine whether the declined transaction was:

- ATM withdrawal
- POS/merchant payment
- Online/e-commerce payment

### Step 2

Check whether the card is active using the authorized banking support system.

Possible statuses:

- Active
- Temporarily blocked
- Permanently blocked
- Expired

### Step 3

Check applicable transaction restrictions.

Check:

- Online transaction enabled
- International transaction enabled
- ATM withdrawal enabled
- Daily transaction limit

### Step 4

If the card is active and there is no restriction:

1. Ask the customer to wait a few minutes.
2. Retry the transaction once.
3. If possible, try another authorized merchant or ATM.

Do not repeatedly retry a potentially blocked transaction.

### Step 5

If money was debited despite the transaction being declined:

- Do not ask the customer to make another payment immediately.
- Check the transaction status.
- Follow the failed transaction/dispute procedure.

## Escalation

Escalate to L2 if:

- Card status cannot be determined.
- Repeated transactions fail.
- Fraud is suspected.
- Customer reports an unknown transaction.
- Money was debited but transaction status is unclear.
- Core banking/card processing reports an error.
- The issue is not covered by this SOP.

## Security

Never request:

- Card PIN
- CVV
- OTP
- Password
- Full card number
