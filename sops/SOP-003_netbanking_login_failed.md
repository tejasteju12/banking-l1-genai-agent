# SOP-003

Title: Net Banking Login Failure
Category: Net Banking
Issue: Login Failure
Support Level: L1
Version: 1.0
Status: Active

## Symptoms

Customer cannot log into net banking.

Examples:

- Login unsuccessful
- Password not accepted
- Account locked
- OTP not received
- Website not loading

## Resolution Steps

### Step 1

Identify the failure type:

- Incorrect credentials
- Account locked
- OTP issue
- Browser/application issue
- Service availability issue

### Step 2

Check basic connectivity:

1. Verify internet connectivity.
2. Use the bank's official website/application.
3. Restart browser/application.
4. Retry after a short interval.

Never request the customer's password or OTP.

### Step 3

If the customer forgot the password:

- Use the bank-approved password reset process.
- Complete the approved identity verification process.
- Do not manually collect credentials.

### Step 4

If the account is locked:

- Check account status using the authorized support system.
- Follow the approved unlock process if L1 is authorized.
- Otherwise escalate to L2.

### Step 5

If OTP is not received:

Check:

- Registered mobile connectivity
- Mobile signal
- SMS service availability
- Banking service status

Never request the OTP itself.

## Escalation

Escalate when:

- Account status cannot be determined.
- Authentication continues to fail.
- Account compromise is suspected.
- OTP infrastructure appears unavailable.
- Unauthorized login is reported.
- Privileged access is required.

## Security

Never request:

- Password
- OTP
- PIN
- CVV
- Full card number
